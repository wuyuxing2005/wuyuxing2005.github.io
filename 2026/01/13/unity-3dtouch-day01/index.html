unity配置与插件安装

发表于2026-01-13|更新于2026-11-06|3dtouch与机械臂开发
|浏览量:

本工作是在已经使用opengl开发过3dtouch设备之后进行的。因此仅仅关注于使用unity开发

本文章是在openhaptics驱动已经安装于unity已经安装的背景下进行unity环境的配置
（还是提一嘴，unityhub中下载引擎时如果报红字无法下载，尝试挂vpn选择TUN模式于全局模式解决）

点击直接跳转unity素材商城openhaptics插件

点击添加到我的资源

注意创建项目时选择built-in 渲染的3d项目：

这里是因为新版的默认3d项目render是URP渲染方式，但项目采用的是旧的built-in。二者部分不兼容

之后打开unity进入已有项目后在window（窗口）-Package Managemnet中的我的资产中找到你的插件(要稍微等待一会才会刷出来插件,大概10s)

点击将1.1导入项目

内容全部导入即可，弹出的备份的提示选no即可

导入完成后的下方出现3dsystems文件夹

点击项目设置（project setting）找到物理（physics）中的玩家选项（player），
将api兼容级别（ Api Compatibility Level*）改为图示选项

接着点击物理（physics）中的设置（setting）选项，将启动自适应力（ Enable Adaptive Force）启用，同时将默认接触偏移（Default Contact Offset）设为0.001(初始是0.01)

如果有
InvalidOperationException: You are trying to read Input using the UnityEngine.Input class, but you have switched active Input handling to Input System package in Player Settings.
UnityEngine.Input.GetKeyDown (UnityEngine.KeyCode key) (at <963eca93f6f94ccd8e0ec96595c4884f>:0)
SceneControl.UpdateKeys () (at Assets/3DSystems/HapticsDirect/HapticScripts/SceneControl.cs:51)
SceneControl.Update () (at Assets/3DSystems/HapticsDirect/HapticScripts/SceneControl.cs:198)
报错
那么在编辑器中点击Edit-Project Settings-Player-Other Settings-Active Input Handling，选择both即可，该操作会重启引擎

此时观察到加载成功，你可以尝试运行项目

能够成功运行就配置好了！！！

如果有报错还是问gpt吧，国内与外网关于这块的求助与帮助帖子确实不多…
